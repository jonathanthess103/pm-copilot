# Closing line for Blueprint skills

Every Blueprint skill that writes ends with `Read: [files]. Saved: [files]. Not read: [files].`

- **Read:** every file opened this session.
- **Saved:** every file this session created.
- **Not read:** every other file in the opp's Blueprint folder, plus every roadmap source not opened. A roadmap source that isn't on disk is marked "(missing)".
- Files are always named, never counted.
- A skill that works on several deals gives one line per deal.

The workspace "Opened: / Not opened:" line, where it applies, still follows this one.
